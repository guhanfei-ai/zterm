# zTerm 使用指南

面向使用者的安装、配置与排障说明。开发相关内容见 [README](../README.zh-CN.md)。

## 平台支持状态

| 平台 | 状态 | 说明 |
| --- | --- | --- |
| macOS (Apple Silicon) | ✅ 可用 | 已验证的主要平台 |
| macOS (Intel) | ⚠️ 未验证 | 无原生构建，可通过 Rosetta 尝试 |
| Windows x64 | ⚠️ CI 可构建，未真机验证 | 试用前先找一台 Windows 机器确认 |
| Linux | ⚠️ CI 可构建，未真机验证 | 应用内更新暂不支持 Linux |

## 安装

### macOS

1. 下载 `zterm-<版本号>-macos-arm64.dmg`，双击挂载后将 zTerm 拖入"应用程序"。
2. **首次打开**：当前安装包未经过 Apple 公证（notarization），直接双击会提示"无法打开"或"已损坏"。这是正常的，任选一种方式放行：
   - 在"应用程序"里找到 zTerm，**右键 → 打开 → 再点"打开"**（只需做一次）；或
   - 打开"终端"执行：`xattr -cr /Applications/zTerm.app`
3. 之后的启动不再需要上述操作。

> 若团队后续配置了 Apple Developer 账号并完成公证，此步骤会被移除。

### Windows

下载 `zterm-<版本号>-windows-x64-setup.exe` 安装。如 SmartScreen 拦截，点"更多信息 → 仍要运行"。

## 首次配置

### 1. 配置 AI（可选，但推荐）

打开 **设置（左侧导航栏齿轮）→ 模型服务**，填写：

- Base URL：OpenAI 兼容接口地址
- API Key：自己的密钥（保存在本机，不会上传）
- 模型名称

不配置 AI 也能正常使用终端，只是右侧聊天/Agent 面板不可用。

### 2. 添加 SSH 主机

**方式一：手动添加。** 左侧"远程主机"面板点 **+**，填写主机名/IP、端口、用户名，认证方式三选一：

- 密码
- 私钥文件（选择本机私钥路径，可带口令）
- 内置密钥（在"秘钥管理"中粘贴私钥内容）

**方式二：从 OpenSSH 配置导入（团队推荐）。** 如果你有现成的 `~/.ssh/config`：

1. 左侧面板点 **导入按钮（↓ 图标）**，选择配置文件；
2. 预览列表会显示每台主机的地址、用户、认证方式，已存在的会标记"已存在"；
3. 勾选需要的机器点"导入"。带 `IdentityFile` 的主机自动使用私钥文件认证，其余为密码认证（**密码不会从配置文件导入，需导入后双击主机编辑填写**）；
4. 通配符块（`Host *`）和 `Match` 块不会导入；`ProxyJump` 等不支持的字段会在预览里标注"已忽略"。

**导出**：左侧面板点 **导出按钮（↑ 图标）**，把当前主机列表导出为 OpenSSH config 格式分享给同事。导出文件**不包含密码、私钥内容和口令**，密码认证的主机会在文件中注明需要重新填写。

### 3. 配置 Jumpserver（可选）

切换到左侧 Jumpserver 模式，新建实例并填写地址与 **Access Key** 认证信息。当前仅支持 access_key 认证方式；资产浏览和连接走 Koko SSH 通道。

## 日常使用

- **多标签**：终端可开多个标签，每个标签独立连接；断线后标签保留，点标签上的"重连"按钮在原标签恢复（不会新开标签）。
- **终端搜索**：`Cmd+F`（Windows/Linux `Ctrl+F`）或工具栏放大镜图标。Enter 下一个 / Shift+Enter 上一个 / Esc 关闭，可切换大小写敏感。
- **导出终端记录**：工具栏下载图标，把当前标签的全部滚动内容（含 10000 行回溯）导出为 `.log` 文件，文件头带标签名、主机和导出时间。
- **工作区恢复**：退出后再启动，可选择"恢复上次工作区"找回全部标签与主机绑定；聊天记录的消息正文也会一并恢复（Agent 运行状态不恢复，属正常）。
- **主机指纹确认**：首次连接一台主机会弹出指纹确认（SHA256），**请先通过其他可信渠道核对指纹再选择"长期信任"**；指纹变化会直接阻断连接，需在主机列表中右键"重置信任"后重新确认。

## 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| macOS 提示"应用已损坏，无法打开" | 安装包未公证。右键 → 打开，或执行 `xattr -cr /Applications/zTerm.app` |
| 连接报"SSH 主机身份已变更，连接已阻断" | 服务器密钥变了（重装/换 IP 指向）。确认合法后右键该主机"重置信任"，重新连接并重新确认指纹 |
| 连接报"未确认主机身份" | 指纹弹窗超时未处理，重新点击连接即可 |
| 连接报鉴权失败 | 用户名/密码/密钥不对；密码认证的主机从配置导入后需要先编辑填写密码 |
| 连接超时 / 网络错误 | 检查地址、端口、VPN/跳板可达性 |
| AI 不回复 | 未配置模型服务或 API Key 无效；AI 功能不影响终端使用 |
| 聊天记录丢了 | 只有正常退出前的内容会被保存；选择"新建空白工作区并清除保存内容"会同时清除聊天历史 |

## 数据存放在哪里

所有配置和记录保存在本机 `~/.zterm/` 目录（`config.json` 等）。密码等敏感信息使用系统级加密存储（macOS Keychain / Windows DPAPI）。

- **备份**：复制 `~/.zterm/` 即可迁移主机列表、密钥引用和工作区。
- **重置**：退出应用后删除 `~/.zterm/` 目录，下次启动等同全新安装。
- **卸载**：删除应用程序 + 删除 `~/.zterm/` 目录。

## 团队分发建议

1. 由一名成员录好主机列表，用"导出"生成 config 文件放入团队共享；
2. 其他成员安装后用"导入"一键获得主机列表，各自补填密码；
3. 新机器加入时重复第 2 步即可，避免每人手工配置。
